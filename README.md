# 劉代洋教授｜經濟學教科書審閱版

本儲存庫僅收錄《自序與建議 20 章架構》審閱網頁，供作者及編輯討論。

- 審閱網頁： https://fci1007-design.github.io/liu-economics-book-review/
- 內容狀態：**審閱初稿，未經劉教授定稿**。
- 章節架構：根據 996 頁既有 EMBA 經濟學教學簡報的原第 1–23 章整理為建議 20 章；書名、案例選擇及章節順序仍需審閱確認。
- 本儲存庫不包含原始簡報、講義全文、圖片素材庫、內部工作檔、專案敏感資料。

## 長者友善審閱介面（第二版）

- 「閱讀自序／20章目錄／審閱重點」三個主畫面分離，減少同一頁的資訊量。
- 章節目錄使用高對比篇別標題、加粗章名、大型數字與清楚邊框；避免相鄰章節視覺上混在一起。
- 點入章節後一次只顯示**一章**，提供明確的「上一章／下一章／返回目錄」。
- 可切換標準字、大字、特大字；字體設定會留在目前瀏覽器中。
- 已測試320、360、390、768、1440px畫面，以及三種字體大小，章節切換正常、無水平溢出。
